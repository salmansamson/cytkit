# USB digital oscilloscope (Picoscope 5000-Series)

>i (For Cytkit 1S-1F only. Not required for Cytkit 2S-14F.)

The recommended USB digital oscilloscope is any of the Picoscope 5000-Series. The Picoscope software is used for alignment. The relevant Honeychrome driver acquires data using the Picoscope SDK.
